Naijaworld-news 

 ❔ About The Project

NaijaWorld is a modern AI-powered news aggregation platform that collects and displays news from Nigerian and global media outlets in real time.

The goal of this project was to practice API integration, responsive UI architecture, and modern frontend engineering principles.

👑 Features

- Real-time news updates✅
- Dark/light mode
- AI-generated summaries
- Search functionality
- Responsive mobile design✅
- Category filtering
- Bookmark system

⚙️ TechStack

- HTML5 ✅
- CSS3✅
- JavaScript✅
- React
- Tailwind CSS
- Firebase
- NewsAPI
